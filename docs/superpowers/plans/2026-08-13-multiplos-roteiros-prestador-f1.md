# Múltiplos Roteiros por Prestador — F1 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hospitais multi-serviço: admin vincula roteiros EXTRAS por unidade (`provider_extra_scripts`); a abertura de ciclo cria 1 instância por (unidade × roteiro extra); o prestador vê e responde todas. Parecer/selo/certificado/plano/pesquisa: por instância, inalterados.

**Architecture:** Tabela permanente `provider_extra_scripts` (chave durável `roteiro_cod`, FK `script_id ON DELETE SET NULL` por causa do reimport destrutivo de roteiros) + 2 endpoints staff + 1 INSERT extra no `openCycleCore` + painel admin na aba Documentos e Qualificação + filtro da lista de roteiros do prestador derivado das instâncias.

**Tech Stack:** Express + `pg`, migrations SQL versionadas, React 19 + TS, Tailwind, lucide-react.

- **Node fora do PATH:** usar `"/c/Program Files/nodejs/node"` / `"/c/Program Files/nodejs/npm"` (Bash tool). Lint: `npm run lint` (`tsc --noEmit`).
- **Migration nova = `0030_provider_extra_scripts.sql`** (última existente: `0029`). Aplicar com `npm run db:migrate` **somente com `APP_ENV=dev`** (conferir `grep -E '^\s*APP_ENV' .env`).
- **Reimport de roteiros é destrutivo** (`eval_scripts` novos; FKs antigas viram NULL): por isso `script_id` é `ON DELETE SET NULL` e `roteiro_cod` (`FOR-XXX`, extraído de `eval_scripts.source_file` com a regex `/FOR-?(\d+)/i` — mesma família do `resolveScriptIds` de `db/import-providers.ts:26`) é a chave durável + script de re-vínculo.

- **Regressão zero:** prestador sem vínculo extra se comporta exatamente como hoje.
- Papéis: GET = admin+auditoria; PUT = **só admin** (`requireAdmin` já existe).
- `isStaff`, `withTransaction`, `auditLog`, `hashClientIp` já existem em `server.ts` — reusar.

```sql
-- 0030_provider_extra_scripts.sql
-- Roteiros EXTRAS por unidade (spec múltiplos roteiros — hospitais multi-serviço).
-- O roteiro principal continua em providers.eval_script_id (resolvido pelo grupo).
-- script_id é ON DELETE SET NULL porque o reimport de roteiros recria eval_scripts;
-- roteiro_cod (FOR-XXX) é a chave durável usada pelo db:relink-extra-scripts.

CREATE TABLE IF NOT EXISTS provider_extra_scripts (
  id          bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  provider_id bigint NOT NULL REFERENCES providers(id) ON DELETE CASCADE,
  location_id bigint NOT NULL REFERENCES provider_locations(id) ON DELETE CASCADE,
  script_id   bigint REFERENCES eval_scripts(id) ON DELETE SET NULL,
  roteiro_cod text   NOT NULL,
  created_by  bigint REFERENCES users(id),
  created_at  timestamptz NOT NULL DEFAULT now(),
  UNIQUE (provider_id, location_id, roteiro_cod)
);
CREATE INDEX IF NOT EXISTS provider_extra_scripts_provider_idx ON provider_extra_scripts (provider_id);
CREATE INDEX IF NOT EXISTS provider_extra_scripts_script_idx ON provider_extra_scripts (script_id);
```

```ts
// Re-vincula provider_extra_scripts.script_id após reimport de roteiros
// (import-roteiros recria eval_scripts; a FK antiga vira NULL via ON DELETE SET NULL).
// Chave durável: roteiro_cod (FOR-XXX), casada com eval_scripts.source_file pela
// mesma regra do resolveScriptIds de import-providers. Uso: npm run db:relink-extra-scripts
import { query, pool } from './db.js';

const codNum = (v: string | null | undefined): string | null => {
  const m = /FOR-?(\d+)/i.exec(v ?? '');
  return m ? String(Number(m[1])) : null;
};

async function run() {
  const { rows: scripts } = await query(
    `SELECT id, source_file FROM eval_scripts WHERE is_current IS NOT FALSE`);
  const byNum = new Map<string, number>();
  for (const s of scripts as any[]) {
    const n = codNum(s.source_file);
    if (n) byNum.set(n, Number(s.id));
  }

  const { rows: links } = await query(
    'SELECT id, roteiro_cod, script_id FROM provider_extra_scripts');
  let updated = 0, orphan = 0;
  for (const l of links as any[]) {
    const n = codNum(l.roteiro_cod);
    const target = n != null ? byNum.get(n) : undefined;
    if (target == null) { orphan++; continue; }
    if (String(l.script_id) === String(target)) continue;
    await query('UPDATE provider_extra_scripts SET script_id = $1 WHERE id = $2', [target, l.id]);
    updated++;
  }
  console.log(`${links.length} vínculo(s): ${updated} re-vinculado(s), ${orphan} sem roteiro vigente correspondente.`);
  await pool.end();
}

run().catch((err) => { console.error(err); process.exit(1); });
```

```ts
  // Serviços avaliados — roteiros EXTRAS por unidade (spec múltiplos roteiros).
  // Adicionais ao principal do grupo; viram instâncias na PRÓXIMA abertura de ciclo.
  app.get('/api/providers/:id/extra-scripts', authenticate, async (req: any, res) => {
    try {
      const { role } = req.user;
      if (role !== 'admin' && role !== 'auditoria') {
        return res.status(403).json({ error: 'Unauthorized' });
      }
      const { rows } = await query(`
        SELECT pes.id, pes.location_id, pes.script_id, pes.roteiro_cod,
               COALESCE(NULLIF(pl.logradouro, ''), pl.label, pl.cidade) AS location_label,
               pl.cidade AS location_cidade, pl.uf AS location_uf,
               s.title AS script_title
          FROM provider_extra_scripts pes
          JOIN provider_locations pl ON pl.id = pes.location_id
          LEFT JOIN eval_scripts s ON s.id = pes.script_id
         WHERE pes.provider_id = $1
         ORDER BY location_label, s.title NULLS LAST
      `, [req.params.id]);
      res.json(rows);
    } catch (err: any) {
      console.error('GET /providers/:id/extra-scripts:', err);
      res.status(500).json({ error: err.message });
    }
  });

  app.put('/api/providers/:id/extra-scripts', authenticate, requireAdmin, async (req: any, res) => {
    try {
      const providerId = Number(req.params.id);
      const links = Array.isArray(req.body?.links) ? req.body.links : null;
      if (!links) return res.status(400).json({ error: 'links deve ser uma lista' });

      const { rows: [prov] } = await query('SELECT id, eval_script_id FROM providers WHERE id = $1', [providerId]);
      if (!prov) return res.status(404).json({ error: 'Prestador não encontrado' });

      const { rows: locs } = await query('SELECT id FROM provider_locations WHERE provider_id = $1', [providerId]);
      const locSet = new Set(locs.map((l: any) => String(l.id)));
      // Só roteiros vigentes; o código FOR do source_file é a chave durável (reimport).
      const { rows: scripts } = await query("SELECT id, source_file FROM eval_scripts WHERE is_current IS NOT FALSE");
      const codOf = new Map<string, string | null>(scripts.map((s: any) => {
        const m = /FOR-?(\d+)/i.exec(s.source_file ?? '');
        return [String(s.id), m ? `FOR-${m[1]}` : null];
      }));

      const norm: Array<{ location_id: number; script_id: number; roteiro_cod: string }> = [];
      const seen = new Set<string>();
      for (const l of links) {
        const lid = Number(l.location_id), sid = Number(l.script_id);
        if (!Number.isInteger(lid) || !locSet.has(String(lid))) {
          return res.status(400).json({ error: `unidade ${l.location_id} não pertence ao prestador` });
        }
        if (!codOf.has(String(sid))) {
          return res.status(400).json({ error: `roteiro ${l.script_id} inexistente ou não vigente` });
        }
        if (String(sid) === String(prov.eval_script_id)) continue; // principal não é "extra"
        const cod = codOf.get(String(sid));
        if (!cod) return res.status(400).json({ error: `roteiro ${sid} sem código FOR no source_file` });
        const key = `${lid}:${cod}`;
        if (seen.has(key)) continue;
        seen.add(key);
        norm.push({ location_id: lid, script_id: sid, roteiro_cod: cod });
      }

      await withTransaction(async (client) => {
        await client.query('DELETE FROM provider_extra_scripts WHERE provider_id = $1', [providerId]);
        for (const n of norm) {
          await client.query(
            `INSERT INTO provider_extra_scripts (provider_id, location_id, script_id, roteiro_cod, created_by)
             VALUES ($1, $2, $3, $4, $5)`,
            [providerId, n.location_id, n.script_id, n.roteiro_cod, req.user.id]);
        }
      });

      await auditLog({
        query, userId: req.user.id, action: 'provider_extra_scripts_updated',
        meta: { provider_id: providerId, count: norm.length },
        ip: hashClientIp(req),
      });
      res.json({ success: true, count: norm.length });
    } catch (err: any) {
      console.error('PUT /providers/:id/extra-scripts:', err);
      res.status(500).json({ error: err.message });
    }
  });
```

Create `src/pages/admin/ProviderExtraScriptsPanel.tsx`:

```tsx
// Seção "Serviços avaliados" (spec múltiplos roteiros): vincula roteiros EXTRAS
// por unidade comercial de um prestador (hospitais multi-serviço). O roteiro
// principal (grupo) não aparece aqui. Escrita só admin; auditoria vê read-only.
// Vínculos valem a partir da PRÓXIMA abertura de ciclo.
import { useEffect, useMemo, useState } from 'react';
import { fetchApi } from '../../lib/api';
import { ClipboardList, Loader2, MapPin } from 'lucide-react';

const isCommercial = (l: any) =>
  !/^residencial/i.test(l.label || '') && !/-RES$/.test(l.sgu_location_code || '');
const locLabel = (l: any) => {
  const uf = l.uf ? '/' + String(l.uf).toUpperCase() : '';
  const city = l.cidade ? `${l.cidade}${uf}` : '';
  const main = l.logradouro || l.label || 'Unidade';
  return city ? `${main} — ${city}` : main;
};

export default function ProviderExtraScriptsPanel({ provider }: { provider: any }) {
  const user = JSON.parse(localStorage.getItem('user') || '{}');
  const isAdmin = user?.role === 'admin';
  const [scripts, setScripts] = useState<any[]>([]);
  const [links, setLinks] = useState<Set<string>>(new Set()); // `${location_id}:${script_id}`
  const [loading, setLoading] = useState(true);
  const [saving, setSaving] = useState(false);
  const [saved, setSaved] = useState(false);
  const [error, setError] = useState<string | null>(null);

  const locations = (provider.locations || []).filter(isCommercial);
  const extras = useMemo(
    () => scripts.filter((s: any) => s.is_current !== false && String(s.id) !== String(provider.eval_script_id)),
    [scripts, provider.eval_script_id]);

  useEffect(() => {
    Promise.all([
      fetchApi('/eval/scripts'),
      fetchApi(`/providers/${provider.id}/extra-scripts`),
    ])
      .then(([ss, ls]) => {
        setScripts(ss || []);
        setLinks(new Set((ls || [])
          .filter((l: any) => l.script_id != null)
          .map((l: any) => `${l.location_id}:${l.script_id}`)));
      })
      .catch((e: any) => setError(e?.message || 'Erro ao carregar vínculos'))
      .finally(() => setLoading(false));
  }, [provider.id]);

  const toggle = (locId: any, scriptId: any) => {
    if (!isAdmin) return;
    const k = `${locId}:${scriptId}`;
    setLinks(prev => {
      const n = new Set(prev);
      if (n.has(k)) n.delete(k); else n.add(k);
      return n;
    });
    setSaved(false);
  };

  const save = async () => {
    setSaving(true);
    setError(null);
    try {
      const payload = [...links].map(k => {
        const [location_id, script_id] = k.split(':');
        return { location_id: Number(location_id), script_id: Number(script_id) };
      });
      await fetchApi(`/providers/${provider.id}/extra-scripts`, {
        method: 'PUT', body: JSON.stringify({ links: payload }),
      });
      setSaved(true);
    } catch (e: any) {
      setError(e?.message || 'Erro ao salvar vínculos');
    } finally {
      setSaving(false);
    }
  };

  if (loading) {
    return <div className="flex justify-center py-10"><Loader2 className="h-6 w-6 animate-spin text-emerald-600" /></div>;
  }

  return (
    <div className="rounded-xl border border-gray-100 bg-white p-5">
      <div className="mb-1 flex items-center gap-2">
        <ClipboardList className="h-4 w-4 text-[#00995D]" />
        <h3 className="text-sm font-semibold text-gray-700">Serviços avaliados (roteiros extras)</h3>
      </div>
      <p className="mb-4 text-xs text-gray-500">
        Roteiros adicionais ao do grupo, por unidade — para prestadores multi-serviço
        (laboratório, imagem, hemoterapia…). Os vínculos valem a partir da próxima
        abertura de ciclo.
      </p>

      {locations.length === 0 ? (
        <p className="text-sm text-gray-400">Este prestador não tem unidade comercial cadastrada.</p>
      ) : extras.length === 0 ? (
        <p className="text-sm text-gray-400">Nenhum roteiro vigente além do principal.</p>
      ) : (
        <div className="space-y-4">
          {locations.map((loc: any) => (
            <div key={loc.id} className="rounded-lg border border-gray-100 p-3">
              <p className="mb-2 flex items-center gap-1.5 text-sm font-semibold text-gray-800">
                <MapPin className="h-3.5 w-3.5 text-emerald-600" /> {locLabel(loc)}
              </p>
              <div className="space-y-1.5">
                {extras.map((s: any) => (
                  <label key={s.id} className={`flex items-center gap-2 text-sm text-gray-700 ${isAdmin ? 'cursor-pointer' : 'cursor-default'}`}>
                    <input
                      type="checkbox"
                      disabled={!isAdmin}
                      checked={links.has(`${loc.id}:${s.id}`)}
                      onChange={() => toggle(loc.id, s.id)}
                    />
                    {s.title}
                  </label>
                ))}
              </div>
            </div>
          ))}
        </div>
      )}

      {error && <p className="mt-3 text-sm text-red-600">{error}</p>}
      {isAdmin && locations.length > 0 && extras.length > 0 && (

          </button>
          {saved && <span className="text-sm font-medium text-emerald-700">Vínculos salvos.</span>}
        </div>
      )}
    </div>
  );
}
```
