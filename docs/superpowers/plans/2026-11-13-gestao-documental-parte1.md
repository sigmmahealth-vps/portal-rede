# Gestão Documental — Parte 1 (Catálogo de tipos) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Substituir o dropdown chumbado de tipos de documento por um catálogo editável por admin, com validação de formato/tamanho no upload.

**Architecture:** Nova tabela `document_types` (seed via migration, CRUD por admin), coluna `documents.type_id` (FK), API Express no padrão existente, aba em `Admin.tsx` e dropdown dinâmico em `Documentos.tsx`. Validação de formato isolada em função pura testada; tamanho pelo `limits` do multer; tipo-ativo checado no handler.

**Tech Stack:** TypeScript, Express, Postgres (`pg`), multer (disk storage), React + `fetchApi`, `node:test`.

Spec: [docs/superpowers/specs/2026-11-13-gestao-documental-parte1-catalogo-design.md](../specs/2026-11-13-gestao-documental-parte1-catalogo-design.md)

## Global Constraints

- Formatos aceitos no upload de documentos: **PDF, JPG, JPEG, PNG, DOCX**. Tamanho máximo **20 MB**.
- `emissão` (`issue_date`) e `validade` (`expiry_date`) são **opcionais**.
- Imports em TypeScript usam sufixo `.js` (ESM/tsx), ex.: `from './db.js'`.
- Migrations rodam uma vez, em transação ([db/migrate.ts](../../../db/migrate.ts)); devem ser idempotentes (`IF NOT EXISTS`, `ON CONFLICT`).
- Rotas admin usam `authenticate, requireAdmin`; `admin` e `auditoria` são equipe interna, mas **só `admin`** edita o catálogo (`requireAdmin` já exige role `admin`).
- Evidências de qualificação (`documents.type='qualificacao_evidencia'`) **não são tocadas**: ficam com `type_id` nulo.
- Comandos db apontam para o ambiente DEV: prefixar `APP_ENV=dev`.

```ts
// Regras de upload de documentos (Gestão Documental). Formato é função pura (testada
// aqui e usada no fileFilter do multer). Tamanho é constante (limits do multer).
// Tipo-ativo é checado no handler (depende do banco).

export const DOC_MAX_BYTES = 20 * 1024 * 1024; // 20 MB
export const DOC_ACCEPTED_EXT = ['pdf', 'jpg', 'jpeg', 'png', 'docx'] as const;

// Aceita pela EXTENSÃO do nome do arquivo (último ponto). Case-insensitive.
export function isAcceptedDocFormat(filename: string): boolean {
  const dot = filename.lastIndexOf('.');
  if (dot < 0) return false;
  const ext = filename.slice(dot + 1).toLowerCase();
  return (DOC_ACCEPTED_EXT as readonly string[]).includes(ext);
}
```

```ts
// Upload de documentos (Gestão Documental): mesmo disk storage, mas com limite de
// 20 MB e filtro de formato (PDF/JPG/PNG/DOCX). Substitui o `upload` cru na rota.
const docUpload = (req: any, res: any, next: any) => {
  multer({
    storage,
    limits: { fileSize: DOC_MAX_BYTES },
    fileFilter: (_req, file, cb) => cb(null, isAcceptedDocFormat(file.originalname)),
  }).single('file')(req, res, (err: any) => {
    if (err) {
      const isSize = err instanceof multer.MulterError && err.code === 'LIMIT_FILE_SIZE';
      return res.status(400).json({ error: isSize ? 'Arquivo maior que 20 MB' : (err.message || 'Falha no upload') });
    }
    next();
  });
};
```

- [ ] **Step 3: Rotas do catálogo (admin + leitura)**

Modify `server.ts`: logo antes de `app.post('/api/documents', ...)` (~linha 2283), adicionar:

```ts
  // Catálogo de tipos — leitura para o dropdown de upload (só ativos).
  app.get('/api/document-types', authenticate, async (_req: any, res) => {
    const { rows } = await query(
      'SELECT id, nome, categoria, escopo, obrigatorio, ordem FROM document_types WHERE ativo = true ORDER BY categoria NULLS LAST, ordem, nome');
    res.json(rows);
  });

  // Catálogo — administração (lista tudo, inclusive inativos).
  app.get('/api/admin/document-types', authenticate, requireAdmin, async (_req: any, res) => {
    const { rows } = await query(
      'SELECT id, nome, categoria, obrigatorio, escopo, ativo, ordem FROM document_types ORDER BY ordem, nome');
    res.json(rows);
  });

  const CATEGORIAS = ['obrigatoria', 'tecnica', 'regulatoria', 'contratual'];
  const ESCOPOS = ['prestador', 'profissional'];

  app.post('/api/admin/document-types', authenticate, requireAdmin, async (req: any, res) => {
    const { nome, categoria, obrigatorio, escopo, ordem } = req.body;
    if (!nome || !String(nome).trim()) return res.status(400).json({ error: 'Nome é obrigatório' });
    if (categoria != null && !CATEGORIAS.includes(categoria)) return res.status(400).json({ error: 'Categoria inválida' });
    if (escopo != null && !ESCOPOS.includes(escopo)) return res.status(400).json({ error: 'Escopo inválido' });
    try {
      const { rows } = await query(
        `INSERT INTO document_types (nome, categoria, obrigatorio, escopo, ordem)
         VALUES ($1,$2,$3,$4,$5) RETURNING id, nome, categoria, obrigatorio, escopo, ativo, ordem`,
        [String(nome).trim(), categoria ?? null, !!obrigatorio, escopo ?? 'prestador', Number(ordem) || 0]);
      res.json(rows[0]);
    } catch (err: any) {
      if (err.code === '23505') return res.status(400).json({ error: 'Já existe um tipo com esse nome' });
      res.status(500).json({ error: err.message });
    }
  });

  app.put('/api/admin/document-types/:id', authenticate, requireAdmin, async (req: any, res) => {
    const { nome, categoria, obrigatorio, escopo, ativo, ordem } = req.body;
    if (!nome || !String(nome).trim()) return res.status(400).json({ error: 'Nome é obrigatório' });
    if (categoria != null && !CATEGORIAS.includes(categoria)) return res.status(400).json({ error: 'Categoria inválida' });
    if (escopo != null && !ESCOPOS.includes(escopo)) return res.status(400).json({ error: 'Escopo inválido' });
    try {
      const { rows } = await query(
        `UPDATE document_types SET nome=$1, categoria=$2, obrigatorio=$3, escopo=$4, ativo=$5, ordem=$6
          WHERE id=$7 RETURNING id, nome, categoria, obrigatorio, escopo, ativo, ordem`,
        [String(nome).trim(), categoria ?? null, !!obrigatorio, escopo ?? 'prestador', ativo !== false, Number(ordem) || 0, req.params.id]);
      if (!rows.length) return res.status(404).json({ error: 'Tipo não encontrado' });
      res.json(rows[0]);
    } catch (err: any) {
      if (err.code === '23505') return res.status(400).json({ error: 'Já existe um tipo com esse nome' });
      res.status(500).json({ error: err.message });
    }
  });

  // DELETE: soft (ativo=false) se já houver documentos usando o tipo; hard se nenhum usa.
  app.delete('/api/admin/document-types/:id', authenticate, requireAdmin, async (req: any, res) => {
    const { id } = req.params;
    const { rows: used } = await query('SELECT 1 FROM documents WHERE type_id = $1 LIMIT 1', [id]);
    if (used.length) {
      await query('UPDATE document_types SET ativo = false WHERE id = $1', [id]);
      return res.json({ soft: true });
    }
    await query('DELETE FROM document_types WHERE id = $1', [id]);
    res.json({ soft: false });
  });
```

```ts
  app.post('/api/documents', authenticate, docUpload, async (req: any, res) => {
    try {
      const { provider_id, role, id: user_id } = req.user;
      const { type_id, issue_date, expiry_date } = req.body;

      if (!req.file) return res.status(400).json({ error: 'No file uploaded' });
      if (!type_id) return res.status(400).json({ error: 'Tipo de documento é obrigatório' });

      const { rows: tipoRows } = await query('SELECT nome FROM document_types WHERE id = $1 AND ativo = true', [type_id]);
      if (!tipoRows.length) return res.status(400).json({ error: 'Tipo de documento inválido ou inativo' });
      const type = tipoRows[0].nome;

      const targetProviderId = role === 'prestador' ? provider_id : req.body.provider_id;
      if (!targetProviderId) return res.status(400).json({ error: 'Provider ID is required' });

      const file_url = '/uploads/' + req.file.filename;
      const status = 'pendente';
      const upload_date = new Date().toISOString();

      await query("UPDATE documents SET status = 'historico' WHERE provider_id = $1 AND type_id = $2 AND status != 'historico'", [targetProviderId, type_id]);

      const { rows } = await query(
        'INSERT INTO documents (provider_id, type_id, type, issue_date, expiry_date, status, file_url, upload_date, uploaded_by) VALUES ($1,$2,$3,$4,$5,$6,$7,$8,$9) RETURNING id',
        [targetProviderId, type_id, type, issue_date || null, expiry_date || null, status, file_url, upload_date, user_id]
      );

      const { rows: newDocRows } = await query('SELECT * FROM documents WHERE id = $1', [rows[0].id]);
      await auditLog({
        query, userId: user_id, action: 'document_uploaded',
        meta: { provider_id: Number(targetProviderId), document_id: rows[0].id, type, filename: req.file?.originalname ?? null },
        ip: hashClientIp(req),
      });
      res.json(newDocRows[0]);
    } catch (err: any) {
      console.error(err);
      res.status(500).json({ error: err.message });
    }
  });
```

- [ ] **Step 1: Criar o componente da aba**

Create `src/pages/admin/TiposDocumentoTab.tsx`:

```tsx
import { useEffect, useState } from 'react';
import { Plus, Pencil, Trash2 } from 'lucide-react';
import { fetchApi } from '../../lib/api';

interface Tipo {
  id: number; nome: string; categoria: string | null;
  obrigatorio: boolean; escopo: 'prestador' | 'profissional'; ativo: boolean; ordem: number;
}
const CATEGORIAS = ['obrigatoria', 'tecnica', 'regulatoria', 'contratual'];
const vazio = (): Partial<Tipo> => ({ nome: '', categoria: null, obrigatorio: false, escopo: 'prestador', ativo: true, ordem: 0 });

export default function TiposDocumentoTab() {
  const [tipos, setTipos] = useState<Tipo[]>([]);
  const [erro, setErro] = useState('');
  const [editando, setEditando] = useState<Partial<Tipo> | null>(null);

  const carregar = () => fetchApi('/admin/document-types').then(setTipos).catch(e => setErro(e.message));
  useEffect(() => { carregar(); }, []);

  const salvar = async () => {
    if (!editando) return;
    try {
      const body = JSON.stringify(editando);
      if (editando.id) await fetchApi(`/admin/document-types/${editando.id}`, { method: 'PUT', body });
      else await fetchApi('/admin/document-types', { method: 'POST', body });
      setEditando(null); carregar();
    } catch (e: any) { setErro(e.message); }
  };

  const excluir = async (t: Tipo) => {
    if (!confirm(`Excluir/desativar o tipo "${t.nome}"?`)) return;
    try { await fetchApi(`/admin/document-types/${t.id}`, { method: 'DELETE' }); carregar(); }
    catch (e: any) { setErro(e.message); }
  };

  return (
    <div className="space-y-4">
      <div className="flex items-center justify-between">
        <h2 className="text-lg font-bold text-gray-900">Tipos de Documento</h2>
        <button onClick={() => setEditando(vazio())}
          className="flex items-center gap-2 rounded-lg bg-emerald-600 px-4 py-2 text-white hover:bg-emerald-700">
          <Plus size={16} /> Novo Tipo
        </button>
      </div>
      {erro && <div className="rounded bg-red-50 px-3 py-2 text-sm text-red-700">{erro}</div>}

      <table className="min-w-full divide-y divide-gray-200">
        <thead>
          <tr className="text-left text-xs font-medium uppercase text-gray-500">
            <th className="px-4 py-2">Nome</th><th className="px-4 py-2">Categoria</th>
            <th className="px-4 py-2">Escopo</th><th className="px-4 py-2">Ativo</th><th className="px-4 py-2">Ações</th>
          </tr>
        </thead>
        <tbody className="divide-y divide-gray-100">
          {tipos.map(t => (
            <tr key={t.id} className={t.ativo ? '' : 'opacity-50'}>
              <td className="px-4 py-2">{t.nome}</td>
              <td className="px-4 py-2">{t.categoria ?? '—'}</td>
              <td className="px-4 py-2">{t.escopo}</td>
              <td className="px-4 py-2">{t.ativo ? 'Sim' : 'Não'}</td>
              <td className="px-4 py-2">
                <button onClick={() => setEditando(t)} className="mr-3 text-gray-500 hover:text-emerald-600"><Pencil size={16} /></button>
                <button onClick={() => excluir(t)} className="text-gray-500 hover:text-red-600"><Trash2 size={16} /></button>
              </td>
            </tr>
          ))}
        </tbody>
      </table>

      {editando && (
        <div className="fixed inset-0 z-50 flex items-center justify-center bg-black/40">
          <div className="w-full max-w-md space-y-3 rounded-lg bg-white p-6">
            <h3 className="text-lg font-bold">{editando.id ? 'Editar' : 'Novo'} tipo</h3>
            <input className="w-full rounded border px-3 py-2" placeholder="Nome"
              value={editando.nome ?? ''} onChange={e => setEditando({ ...editando, nome: e.target.value })} />
            <select className="w-full rounded border px-3 py-2"
              value={editando.categoria ?? ''} onChange={e => setEditando({ ...editando, categoria: e.target.value || null })}>
              <option value="">(sem categoria)</option>
              {CATEGORIAS.map(c => <option key={c} value={c}>{c}</option>)}
            </select>
            <select className="w-full rounded border px-3 py-2"
              value={editando.escopo ?? 'prestador'} onChange={e => setEditando({ ...editando, escopo: e.target.value as Tipo['escopo'] })}>
              <option value="prestador">prestador</option>
              <option value="profissional">profissional</option>
            </select>
            <input type="number" className="w-full rounded border px-3 py-2" placeholder="Ordem"
              value={editando.ordem ?? 0} onChange={e => setEditando({ ...editando, ordem: Number(e.target.value) })} />
            <label className="flex items-center gap-2 text-sm">
              <input type="checkbox" checked={!!editando.obrigatorio}
                onChange={e => setEditando({ ...editando, obrigatorio: e.target.checked })} /> Obrigatório
            </label>
            {editando.id && (
              <label className="flex items-center gap-2 text-sm">
                <input type="checkbox" checked={editando.ativo !== false}
                  onChange={e => setEditando({ ...editando, ativo: e.target.checked })} /> Ativo
              </label>
            )}
            <div className="flex justify-end gap-2 pt-2">
              <button onClick={() => setEditando(null)} className="rounded px-4 py-2 text-gray-600">Cancelar</button>
              <button onClick={salvar} className="rounded bg-emerald-600 px-4 py-2 text-white hover:bg-emerald-700">Salvar</button>
            </div>
          </div>
        </div>
      )}
    </div>
  );
}
```
