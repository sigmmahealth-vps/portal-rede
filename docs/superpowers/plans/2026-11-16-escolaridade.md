# Escolaridade (autosserviço + validação) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** O prestador cadastra sua formação acadêmica (nível, curso, instituição, conclusão + PDF) que entra como pendente; o admin aprova/reprova no detalhe do prestador. Espelha o fluxo de Certificações.

**Architecture:** Tabela própria `provider_education`; quatro endpoints espelham `/api/certifications`; o detalhe do prestador passa a trazer `education`; uma página `Escolaridade` no portal do prestador; uma seção de validação (`EducacaoAdmin`) na aba "Documentos e Qualificação" do `ProviderDetail`, abaixo de Certificações.

**Tech Stack:** TypeScript (ESM `.js` imports), Postgres (`pg`), Express + multer (`docUpload`), React + `fetchApi`. Sem libs novas.

## Global Constraints

- Imports relativos entre módulos TS usam sufixo `.js` (ESM/tsx).
- Estados: `pendente`/`valido`/`reprovado` (iguais aos documentos/certificações).
- Upload reusa `docUpload` (server.ts:91); arquivo **obrigatório** no POST; `fetchApi` com `FormData`.
- Endpoints de admin exigem `role` admin/auditoria; os do prestador agem sobre o próprio `req.user.provider_id`.
- Níveis válidos (whitelist): `ensino_medio, tecnico, graduacao, especializacao, residencia, mestrado, doutorado, pos_doutorado`.
- Migration nova: `0065` (a última é `0064_provider_certifications_upload.sql`).
- Sem módulo/teste de lib novo (CRUD sem lógica pura). Verificação: `tsc` + build + smoke.
- `conclusao_date` não pode ser futura (guarda inline, como a emissão dos documentos).

```ts
  // ===== Escolaridade (autoinformada pelo prestador, validada pelo admin) =====
  const NIVEIS_EDU = ['ensino_medio','tecnico','graduacao','especializacao','residencia','mestrado','doutorado','pos_doutorado'];

  // Lista as formações do prestador logado. O admin valida no detalhe do prestador.
  app.get('/api/education', authenticate, async (req: any, res) => {
    try {
      const { provider_id } = req.user;
      if (!provider_id) return res.status(400).json({ error: 'Usuário sem prestador vinculado' });
      const { rows } = await query(
        'SELECT * FROM provider_education WHERE provider_id = $1 ORDER BY id DESC', [provider_id]);
      res.json(rows);
    } catch (err: any) {
      res.status(500).json({ error: err.message });
    }
  });

  app.post('/api/education', authenticate, docUpload, async (req: any, res) => {
    try {
      const { role, provider_id, id: user_id } = req.user;
      const { nivel, curso, instituicao, conclusao_date } = req.body;
      const targetProviderId = role === 'prestador' ? provider_id : req.body.provider_id;
      if (!targetProviderId) return res.status(400).json({ error: 'Prestador é obrigatório' });
      if (!NIVEIS_EDU.includes(String(nivel))) return res.status(400).json({ error: 'Nível inválido' });
      if (!req.file) return res.status(400).json({ error: 'Arquivo é obrigatório' });
      const hoje = new Date().toLocaleDateString('en-CA');
      if (conclusao_date && conclusao_date > hoje) return res.status(400).json({ error: 'A conclusão não pode ser futura' });

      const file_url = '/uploads/' + req.file.filename;
      const { rows } = await query(
        `INSERT INTO provider_education
           (provider_id, nivel, curso, instituicao, conclusao_date, status, file_url, uploaded_by, upload_date)
         VALUES ($1,$2,$3,$4,$5,'pendente',$6,$7,now()) RETURNING id`,
        [targetProviderId, String(nivel), curso || null, instituicao || null, conclusao_date || null, file_url, user_id]);
      const { rows: created } = await query('SELECT * FROM provider_education WHERE id = $1', [rows[0].id]);
      await auditLog({ query, userId: user_id, action: 'education_created',
        meta: { provider_id: Number(targetProviderId), education_id: rows[0].id, nivel: String(nivel) },
        ip: hashClientIp(req) });
      res.json(created[0]);
    } catch (err: any) {
      console.error(err);
      res.status(500).json({ error: err.message });
    }
  });

  app.put('/api/education/:id/status', authenticate, async (req: any, res) => {
    try {
      const { role } = req.user;
      if (role !== 'admin' && role !== 'auditoria') return res.status(403).json({ error: 'Unauthorized' });
      const { status, rejection_reason } = req.body;
      if (!['valido', 'reprovado'].includes(status)) return res.status(400).json({ error: 'Status inválido' });
      const { rows } = await query(
        `UPDATE provider_education SET status = $1, rejection_reason = $2 WHERE id = $3 RETURNING *`,
        [status, status === 'reprovado' ? (rejection_reason || null) : null, req.params.id]);
      if (!rows.length) return res.status(404).json({ error: 'Formação não encontrada' });
      await auditLog({ query, userId: req.user.id, action: 'education_status_changed',
        meta: { provider_id: Number(rows[0].provider_id), education_id: Number(req.params.id), status },
        ip: hashClientIp(req) });
      res.json(rows[0]);
    } catch (err: any) {
      res.status(500).json({ error: err.message });
    }
  });

  app.delete('/api/education/:id', authenticate, async (req: any, res) => {
    try {
      const { role, provider_id } = req.user;
      const { rows } = await query('SELECT * FROM provider_education WHERE id = $1', [req.params.id]);
      const edu = rows[0] as any;
      if (!edu) return res.status(404).json({ error: 'Formação não encontrada' });
      if (role === 'prestador' && edu.provider_id !== provider_id) return res.status(403).json({ error: 'Unauthorized' });
      if (edu.status !== 'pendente') return res.status(400).json({ error: 'Só formações pendentes podem ser excluídas' });
      await query('DELETE FROM provider_education WHERE id = $1', [req.params.id]);
      res.json({ ok: true });
    } catch (err: any) {
      res.status(500).json({ error: err.message });
    }
  });
```

```tsx
import { useEffect, useState } from 'react';
import { fetchApi } from '../lib/api';
import { Plus, Trash2, FileText } from 'lucide-react';

type Edu = {
  id: number; nivel: string; curso: string | null; instituicao: string | null;
  conclusao_date: string | null; status: string; rejection_reason: string | null; file_url: string | null;
};

const NIVEL_LABEL: Record<string, string> = {
  ensino_medio: 'Ensino Médio', tecnico: 'Técnico', graduacao: 'Graduação',
  especializacao: 'Especialização', residencia: 'Residência', mestrado: 'Mestrado',
  doutorado: 'Doutorado', pos_doutorado: 'Pós-Doutorado',
};
const NIVEIS = Object.keys(NIVEL_LABEL);
const STATUS: Record<string, { label: string; cls: string }> = {
  pendente: { label: 'Pendente', cls: 'bg-blue-50 text-blue-700' },
  valido: { label: 'Válido', cls: 'bg-emerald-50 text-emerald-700' },
  reprovado: { label: 'Reprovado', cls: 'bg-red-50 text-red-700' },
};
const fmt = (d: string | null) => (d ? d.slice(0, 10).split('-').reverse().join('/') : '—');

export default function Escolaridade() {
  const [itens, setItens] = useState<Edu[]>([]);
  const [carregando, setCarregando] = useState(true);
  const [erro, setErro] = useState('');
  const [modal, setModal] = useState(false);

  const load = () => {
    setCarregando(true);
    setErro('');
    fetchApi('/education').then(setItens).catch(e => setErro(e.message)).finally(() => setCarregando(false));
  };
  useEffect(load, []);

  async function excluir(id: number) {
    if (!window.confirm('Excluir esta formação?')) return;
    setErro('');
    try { await fetchApi(`/education/${id}`, { method: 'DELETE' }); load(); }
    catch (e: any) { setErro(e.message); }
  }

  return (
    <div className="space-y-4">
      <div className="flex items-center justify-between">
        <h1 className="text-2xl font-bold text-gray-900">Escolaridade</h1>
        <button onClick={() => setModal(true)}
          className="inline-flex items-center gap-1.5 rounded-lg bg-emerald-600 px-3 py-2 text-sm font-medium text-white hover:bg-emerald-700">
          <Plus className="h-4 w-4" /> Adicionar formação
        </button>
      </div>
      {erro && <div className="rounded-md bg-red-50 px-3 py-2 text-sm text-red-700">{erro}</div>}

      {carregando ? <div className="p-8 text-center text-gray-400">Carregando…</div>

        : !itens.length ? <div className="rounded-xl border border-gray-100 bg-white p-8 text-center text-gray-400">Nenhuma formação cadastrada.</div>
        : (
        <div className="overflow-x-auto rounded-xl border border-gray-100 bg-white">
          <table className="w-full text-sm">
            <thead><tr className="border-b border-gray-100 text-left text-gray-500">
              <th className="px-4 py-3 font-medium">Curso</th>
              <th className="px-4 py-3 font-medium">Nível</th>
              <th className="px-4 py-3 font-medium">Instituição</th>
              <th className="px-4 py-3 font-medium">Conclusão</th>
              <th className="px-4 py-3 font-medium">Status</th>
              <th className="px-4 py-3 font-medium">Ações</th>
            </tr></thead>
            <tbody>
              {itens.map(e => (
                <tr key={e.id} className="border-b border-gray-50 last:border-0">
                  <td className="px-4 py-3 text-gray-900">
                    {e.file_url ? <a href={e.file_url} target="_blank" rel="noreferrer" className="inline-flex items-center gap-1 text-emerald-700 hover:underline"><FileText className="h-4 w-4" />{e.curso ?? '—'}</a> : (e.curso ?? '—')}
                    {e.status === 'reprovado' && e.rejection_reason && <div className="text-xs text-red-600">{e.rejection_reason}</div>}
                  </td>
                  <td className="px-4 py-3 text-gray-600">{NIVEL_LABEL[e.nivel] ?? e.nivel}</td>
                  <td className="px-4 py-3 text-gray-600">{e.instituicao ?? '—'}</td>

function AddModal({ onClose, onDone }: { onClose: () => void; onDone: () => void }) {
  const hojeISO = new Date().toLocaleDateString('en-CA');
  const [form, setForm] = useState({ nivel: '', curso: '', instituicao: '', conclusao_date: '' });
  const [file, setFile] = useState<File | null>(null);
  const [erro, setErro] = useState('');
  const [enviando, setEnviando] = useState(false);
  const set = (k: string, v: string) => setForm(f => ({ ...f, [k]: v }));

  async function salvar() {
    setErro('');
    if (!form.nivel) return setErro('Selecione o nível.');
    if (!file) return setErro('Anexe o comprovante.');
    if (form.conclusao_date && form.conclusao_date > hojeISO) return setErro('A conclusão não pode ser futura.');
    setEnviando(true);
    const fd = new FormData();
    fd.append('file', file);
    for (const [k, v] of Object.entries(form) as [string, string][]) if (v) fd.append(k, v);
    try { await fetchApi('/education', { method: 'POST', body: fd }); onDone(); }
    catch (e: any) { setErro(e.message); setEnviando(false); }
  }

  return (
    <div className="fixed inset-0 z-50 flex items-center justify-center bg-black/40 p-4">
      <div className="w-full max-w-lg rounded-2xl bg-white p-6 shadow-xl">
        <h2 className="mb-4 text-lg font-bold text-gray-900">Adicionar formação</h2>
        {erro && <div className="mb-3 rounded-md bg-red-50 px-3 py-2 text-sm text-red-700">{erro}</div>}
        <div className="grid grid-cols-1 gap-3 sm:grid-cols-2">
          <label className="text-sm">Nível*<select className="mt-1 w-full rounded-lg border border-gray-300 px-3 py-2" value={form.nivel} onChange={e => set('nivel', e.target.value)}>
            <option value="">Selecione…</option>
            {NIVEIS.map(n => <option key={n} value={n}>{NIVEL_LABEL[n]}</option>)}
          </select></label>
          <label className="text-sm">Conclusão<input type="date" max={hojeISO} className="mt-1 w-full rounded-lg border border-gray-300 px-3 py-2" value={form.conclusao_date} onChange={e => set('conclusao_date', e.target.value)} /></label>
          <label className="sm:col-span-2 text-sm">Curso<input className="mt-1 w-full rounded-lg border border-gray-300 px-3 py-2" value={form.curso} onChange={e => set('curso', e.target.value)} /></label>
          <label className="sm:col-span-2 text-sm">Instituição<input className="mt-1 w-full rounded-lg border border-gray-300 px-3 py-2" value={form.instituicao} onChange={e => set('instituicao', e.target.value)} /></label>
          <label className="sm:col-span-2 text-sm">Comprovante*<input type="file" className="mt-1 w-full text-sm" onChange={e => setFile(e.target.files?.[0] ?? null)} /></label>
        </div>
        <div className="mt-5 flex justify-end gap-2">
          <button onClick={onClose} className="rounded-lg px-4 py-2 text-sm text-gray-600 hover:bg-gray-100">Cancelar</button>
          <button onClick={salvar} disabled={enviando} className="rounded-lg bg-emerald-600 px-4 py-2 text-sm font-medium text-white hover:bg-emerald-700 disabled:opacity-50">{enviando ? 'Enviando…' : 'Salvar'}</button>
        </div>
      </div>
    </div>
  );
}
```

```tsx
import { useState } from 'react';
import { fetchApi } from '../../lib/api';
import { FileText, Check, X } from 'lucide-react';

type Edu = {
  id: number; nivel: string; curso: string | null; instituicao: string | null;
  conclusao_date: string | null; status: string; rejection_reason: string | null; file_url: string | null;
};
const NIVEL_LABEL: Record<string, string> = {
  ensino_medio: 'Ensino Médio', tecnico: 'Técnico', graduacao: 'Graduação',
  especializacao: 'Especialização', residencia: 'Residência', mestrado: 'Mestrado',
  doutorado: 'Doutorado', pos_doutorado: 'Pós-Doutorado',
};
const STATUS: Record<string, { label: string; cls: string }> = {
  pendente: { label: 'Pendente', cls: 'bg-blue-50 text-blue-700' },
  valido: { label: 'Válido', cls: 'bg-emerald-50 text-emerald-700' },
  reprovado: { label: 'Reprovado', cls: 'bg-red-50 text-red-700' },
};
const fmt = (d: string | null) => (d ? d.slice(0, 10).split('-').reverse().join('/') : '—');

export default function EducacaoAdmin({ education, onChange }: { education: Edu[]; onChange: () => void }) {
  const [erro, setErro] = useState('');
  const [busyId, setBusyId] = useState<number | null>(null);

  async function mudar(id: number, status: 'valido' | 'reprovado') {
    setErro('');
    let rejection_reason: string | undefined;
    if (status === 'reprovado') {
      const m = window.prompt('Motivo da reprovação:');
      if (m === null) return;
      if (!m.trim()) { setErro('Informe o motivo da reprovação.'); return; }
      rejection_reason = m.trim();
    }
    setBusyId(id);
    try {
      await fetchApi(`/education/${id}/status`, { method: 'PUT', body: JSON.stringify({ status, rejection_reason }) });
      onChange();
    } catch (e: any) { setErro(e.message); }
    finally { setBusyId(null); }
  }

  if (!education.length)
    return <div className="rounded-xl border border-gray-100 bg-white p-6 text-center text-sm text-gray-400">Nenhuma formação enviada por este prestador.</div>;

  return (
    <div className="space-y-2">
      {erro && <div className="rounded-md bg-red-50 px-3 py-2 text-sm text-red-700">{erro}</div>}
      <div className="overflow-x-auto rounded-xl border border-gray-100 bg-white">
        <table className="w-full text-sm">
          <thead><tr className="border-b border-gray-100 text-left text-gray-500">
            <th className="px-4 py-3 font-medium">Curso</th>
            <th className="px-4 py-3 font-medium">Nível</th>
            <th className="px-4 py-3 font-medium">Instituição</th>
            <th className="px-4 py-3 font-medium">Status</th>
            <th className="px-4 py-3 font-medium">Ações</th>
          </tr></thead>
          <tbody>
            {education.map(e => (
              <tr key={e.id} className="border-b border-gray-50 last:border-0">
                <td className="px-4 py-3 text-gray-900">
                  {e.file_url ? <a href={e.file_url} target="_blank" rel="noreferrer" className="inline-flex items-center gap-1 text-emerald-700 hover:underline"><FileText className="h-4 w-4" />{e.curso ?? '—'}</a> : (e.curso ?? '—')}
                  {e.status === 'reprovado' && e.rejection_reason && <div className="text-xs text-red-600">{e.rejection_reason}</div>}
                </td>
                <td className="px-4 py-3 text-gray-600">{NIVEL_LABEL[e.nivel] ?? e.nivel}</td>
                <td className="px-4 py-3 text-gray-600">{e.instituicao ?? '—'}</td>
                <td className="px-4 py-3"><span className={`rounded-full px-2 py-0.5 text-xs ${STATUS[e.status]?.cls ?? ''}`}>{STATUS[e.status]?.label ?? e.status}</span></td>
                <td className="px-4 py-3">
                  {e.status === 'pendente' && (
                    <div className="flex gap-2">
                      <button disabled={busyId === e.id} onClick={() => mudar(e.id, 'valido')} title="Aprovar" className="text-emerald-600 hover:text-emerald-800 disabled:opacity-40"><Check className="h-4 w-4" /></button>
                      <button disabled={busyId === e.id} onClick={() => mudar(e.id, 'reprovado')} title="Reprovar" className="text-red-600 hover:text-red-800 disabled:opacity-40"><X className="h-4 w-4" /></button>
                    </div>
                  )}
                </td>
              </tr>
            ))}
          </tbody>
        </table>
      </div>
    </div>
  );
}
```
