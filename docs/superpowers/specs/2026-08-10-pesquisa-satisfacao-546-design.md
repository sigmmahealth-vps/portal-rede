# Pesquisa de Satisfação nativa (spec 5.4.6) — Design

Data: 2026-08-10

## Objetivo

Substituir links externos por uma **Pesquisa de Satisfação nativa** no portal,
disparada ao fim do envio do roteiro de qualificação, com:

- prazo de **7 dias corridos** após o envio do roteiro;
- **bônus automático de 10 pontos** na pontuação do ciclo quando respondida no prazo;
- **Dashboard de Indicadores** para o admin/staff, com **NPS** e listagem detalhada.

## Estado atual (ponto de partida)

- O tab "Pesquisa de Satisfação" em [PrestadorView.tsx](../../src/pages/qualificacao/PrestadorView.tsx) é um placeholder "Em breve".
- Existe uma pesquisa **legada** simples: [Pesquisa.tsx](../../src/pages/Pesquisa.tsx), endpoint `/api/surveys` e tabela `survey_responses` (atendimento/comunicação/sugestões). Será aposentada.
- `eval_instances` **não** guarda timestamp do envio do roteiro; o `/submit` só muda o status para `em_analise`.
- O selo sai de `percentual = score/max_possible*100` → `computeSeal(percentual, elim)` no `/parecer`.

## Decisões (aprovadas)

1. **Bônus**: soma **+10 pontos percentuais** ao percentual final, **teto 100**, antes de calcular o selo. Só quando a pesquisa foi respondida **dentro do prazo**; senão +0.
2. **NPS**: **pergunta dedicada (Q6)** em escala **0–10**, ancorada na **plataforma**. O Q5 (estrelas 1–5) continua medindo o processo (CSAT).
3. **Sequenciamento**: o `/parecer` **bloqueia** enquanto a pesquisa não for respondida **e** o prazo de 7 dias não vencer. Garante bônus (ou 0) definido antes do selo.
4. **Notificação**: banner in-app + aba (como no mockup). Sem e-mail nesta versão.
5. **Legado**: aposentar `Pesquisa.tsx` + rota + `/api/surveys`; manter a tabela `survey_responses` (dados históricos), sem uso novo.

## Formulário (6 perguntas + comentários)

| # | Pergunta | Tipo | Alimenta |
|---|---|---|---|
| Q1 | Clareza das instruções/orientações do roteiro | estrelas 1–5 | CSAT |
| Q2 | Facilidade de uso do portal para envio das evidências | estrelas 1–5 | CSAT |
| Q3 | Orientações sobre quais documentos enviar foram suficientes | múltipla escolha | distribuição |
| Q4 | Encontrou dificuldades técnicas ao usar o portal? | Sim/Não + texto | % dificuldade + leitura |
| Q5 | Avaliação geral do **processo de qualificação** | estrelas 1–5 | CSAT |
| Q6 | *"De 0 a 10, o quanto você recomendaria o Portal da Rede Credenciada da Unimed Criciúma a outro prestador?"* (0 = não recomendaria · 10 = recomendaria com certeza) | escala 0–10 | **NPS** |
| — | Comentários e sugestões (opcional) | texto | elogios/críticas/demandas de treinamento |

Q3 — opções (da mais positiva à mais negativa, com uma neutra no meio): `sim_totalmente`, `sim_parcialmente`, `neutro` ("Indiferente — não ajudaram nem atrapalharam"), `nao_precisei_ajuda`, `nao_insuficientes`.

## Modelo de dados

Migration **0027**:

```sql
ALTER TABLE eval_instances ADD COLUMN IF NOT EXISTS submitted_at timestamptz;

CREATE TABLE IF NOT EXISTS eval_survey_responses (
  id              bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  instance_id     bigint NOT NULL UNIQUE REFERENCES eval_instances(id) ON DELETE CASCADE,
  q1_clareza      smallint,      -- 1..5
  q2_portal       smallint,      -- 1..5
  q3_documentos   text,          -- sim_totalmente|sim_parcialmente|nao_precisei_ajuda|nao_insuficientes
  q4_dificuldade  boolean,
  q4_texto        text,
  q5_geral        smallint,      -- 1..5
  q6_nps          smallint,      -- 0..10
  comentarios     text,
  submitted_at    timestamptz NOT NULL DEFAULT now(),
  within_deadline boolean NOT NULL,
  bonus_points    smallint NOT NULL DEFAULT 0  -- 10 se within_deadline, senão 0
);
```

- **Prazo** = `eval_instances.submitted_at + interval '7 days'`.
- `within_deadline` e `bonus_points` são calculados **no momento do envio** da pesquisa (comparando `now()` com o prazo) e ficam congelados na linha.
- Uma pesquisa por avaliação (`instance_id UNIQUE`).

## Fluxo do prestador

Aba "Pesquisa de Satisfação" em `PrestadorView`, alimentada por:

- `GET /api/me/survey` → estado da avaliação corrente do prestador:
  - `sem_roteiro` (nenhuma instância enviada) → aviso "disponível após enviar o roteiro";
  - `disponivel` (instância com `submitted_at`, sem resposta) → mostra o form + prazo (`deadline`, dias restantes);
  - `respondida` → resumo (data + `bonus_points`).
- `POST /api/me/survey` → grava a resposta da instância enviada mais recente do prestador que ainda não tem resposta. Calcula `within_deadline` e `bonus_points`. Escopo anti-IDOR: sempre por `req.user.provider_id`.

O form pode ser enviado **mesmo após o prazo** (grava com `bonus_points = 0`). Se a instância já foi finalizada e sem resposta, o form ainda permite gravar (histórico), mas não altera selo já emitido.

## Integração com a pontuação

- **`/submit`** ([server.ts](../../server.ts)): grava `eval_instances.submitted_at = now()` junto da mudança de status.
- **`/parecer`**:
  1. **Bloqueio**: se não existe resposta **e** `now() < submitted_at + 7 dias` → `409 { error: 'aguardando pesquisa de satisfação ou fim do prazo' }`.
  2. Calcula `percentual` como hoje.
  3. `bonus = (resposta existe && within_deadline) ? 10 : 0`.
  4. `percentualFinal = min(100, percentual + bonus)`.
  5. `seal = computeSeal(percentualFinal, elim)`; grava `percentual = percentualFinal`.
- Certificado mostra o total já com bônus. As dimensões seguem do score bruto (o +10 é um extra sobre o total; dimensões não somam exatamente o total — esperado).

## Dashboard de Indicadores (staff)

Nova aba "Pesquisa de Satisfação" na área staff de Qualificação (ao lado de "Painel do Ciclo"), filtrável por ciclo. Fonte: `GET /api/eval/surveys?cycle_id=`.

- **NPS** (de Q6): contagem/percentual de promotores (9–10), passivos (7–8), detratores (0–6) e `NPS = %promotores − %detratores` (−100..+100).
- **CSAT**: média de Q1, Q2, Q5 (estrelas); distribuição de Q3; % com dificuldade em Q4.
- **Listagem detalhada**: tabela por prestador com as notas + textos (Q4 e comentários), para ler elogios/críticas e levantar demandas de treinamento. Ordenável/legível; sem ocultar respostas.

Cálculo de NPS/CSAT extraído para uma **função pura** (`src/lib/surveyStats.ts`) reutilizável e testável.
