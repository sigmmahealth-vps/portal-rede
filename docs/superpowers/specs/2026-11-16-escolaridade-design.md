# Gestão Documental — Escolaridade (autosserviço + validação) — Design

**Data:** 2026-11-16
**Status:** aprovado (desenho) — pendente revisão da spec escrita

## Contexto e objetivo

Segunda das três sub-fatias de atributos autoinformados pelo prestador (depois de Certificações).
O prestador cadastra sua **formação acadêmica** (nível, curso, instituição, conclusão + diploma/
comprovante em PDF) e o admin valida ou reprova. Mesmo fluxo das Certificações.

Decisões (brainstorm): escolaridade **por prestador** (não por profissional individual — a equipe
em `provider_contacts` está vazia/sem uso) e em **tabela própria** `provider_education` (não reusa
`provider_certifications`, para não misturar conceitos nem forçar campos).

### Fora de escopo
- Escolaridade **por profissional** (amarrada a membros da equipe) — evolução futura.
- **Dados Técnicos** (CNES/ISS/Prontuário) — próxima sub-fatia (depende da diretriz).
- Métricas no Painel; notificação na reprovação; catálogo editável de níveis.

## Modelo de dados

Migration nova `db/migrations/0065_provider_education.sql`:

```sql
CREATE TABLE IF NOT EXISTS provider_education (
  id               bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  provider_id      bigint NOT NULL REFERENCES providers(id) ON DELETE CASCADE,
  nivel            text   NOT NULL CHECK (nivel IN
                     ('ensino_medio','tecnico','graduacao','especializacao','residencia','mestrado','doutorado','pos_doutorado')),
  curso            text,
  instituicao      text,
  conclusao_date   date,
  file_url         text,
  status           text   NOT NULL DEFAULT 'pendente' CHECK (status IN ('pendente','valido','reprovado')),
  rejection_reason text,
  uploaded_by      bigint REFERENCES users(id),
  upload_date      timestamptz,
  created_at       timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX IF NOT EXISTS provider_education_provider_id_idx ON provider_education (provider_id);
```

Os 8 níveis são os valores do dropdown (rótulos legíveis no cliente).

## Servidor (espelha `/api/certifications`)

- `GET /api/education` (`authenticate`): prestador → as suas (`WHERE provider_id = $self`; 400 se sem
  prestador). (Admin valida no detalhe do prestador — sem ramo admin aqui, já que o `GET /api/providers/:id`
  trará `education`.)
- `POST /api/education` (`authenticate, docUpload`): prestador cria. `nivel` obrigatório e dentro do
  conjunto (400 senão); **arquivo obrigatório** (400 se ausente); `conclusao_date` não-futura (400).
  Grava `status='pendente'`, `uploaded_by`, `upload_date`, `file_url`.
- `PUT /api/education/:id/status` (`authenticate`, admin/auditoria): `{ status: 'valido'|'reprovado', rejection_reason? }`.
- `DELETE /api/education/:id` (`authenticate`, prestador dono): remove só se `status='pendente'`.

Validação de arquivo: reusa `docUpload` (formato/tamanho). `NIVEIS` como constante no servidor para a validação.

## Detalhe do prestador (admin)

`GET /api/providers/:id` (server.ts:2048) passa a carregar também:
```sql
SELECT * FROM provider_education WHERE provider_id = $1 ORDER BY conclusao_date DESC NULLS LAST, id DESC
```
e devolve no payload como `education` (ao lado de `certifications`).

## Telas

### Prestador — nova página "Escolaridade"
- Rota `/escolaridade` no portal; item de menu **só para prestador** (ícone `GraduationCap`).
- Lista: curso, nível (rótulo), instituição, conclusão, **status** (cor: pendente=azul, válido=verde,
  reprovado=vermelho + motivo); link do arquivo; excluir enquanto pendente.
- Modal "Adicionar formação": `nivel` (dropdown), `curso`, `instituicao`, `conclusao_date` (date,
  `max=hoje`), **arquivo** (upload). Mesmas validações de data/arquivo do Certificações.

### Admin — validação no detalhe do prestador
- Componente `EducacaoAdmin.tsx` (irmão de `CertificacoesAdmin.tsx`), renderizado na aba
  "Documentos e Qualificação" do `ProviderDetail`, numa seção **Escolaridade** abaixo de Certificações.
- Lista `provider.education` com link do arquivo + **Aprovar/Reprovar** (reprovar pede motivo, exige
  motivo não-vazio) → `PUT /api/education/:id/status`, recarrega (`load`).

## Rótulos de nível (cliente)
`ensino_medio`→"Ensino Médio", `tecnico`→"Técnico", `graduacao`→"Graduação",
`especializacao`→"Especialização", `residencia`→"Residência", `mestrado`→"Mestrado",
`doutorado`→"Doutorado", `pos_doutorado`→"Pós-Doutorado".
